# SolarScreen — Serviceable BIPV Vision Façade

SolarScreen is a **spatially patterned, serviceable BIPV vision-panel** research programme. It is not a clear solar window or a claim that PV can power a bright daytime media façade. Long-lived glass/PV functions and replaceable mullion electronics are separated by design.
