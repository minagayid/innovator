# SolarScreen Coupled Component Model Specification

**Evidence class:** finite coupon/IGU component evaluation. This is not a façade structural, fire, weathering, code, glare, whole-building, or energy-certificate model.

## Falsifiable hypothesis

For a specified orientation and spatial PV/vision geometry, the serviceable BIPV core can be characterized as a combined optical–thermal–electrical component and can compare credibly against a matched passive/BIPV baseline before optional information-layer use is included.

\[
E_{\mathrm{net,core}} = E_{\mathrm{PV}} - E_{\mathrm{conditioning}} - E_{\mathrm{controls}}, \qquad
E_{\mathrm{net,total}} = E_{\mathrm{net,core}} - E_{\mathrm{information}}.
\]

## Controls

| Case | Input change | Required discriminating outcome |
|---|---|---|
| Passive baseline | Matched solar-control glazing, no PV/service cassette. | Establish optical/thermal reference. |
| BIPV baseline | Matched conventional BIPV geometry. | Establish PV/vision reference. |
| Candidate core | Patterned PV vision panel plus service cassette. | Produces auditable joint optical/thermal/electrical measurements. |
| Negative control | Excess opaque fraction or deliberately poor control/electronics duty. | Demonstrates a worse daylight, energy or thermal trade-off. |
| Optional information layer | Specified duty/luminance, separately metered. | Is never included in a claim of core net positivity. |

## Measurements

Record spectral transmission, haze, visual pattern/glare proxy, PV IV curve, cell temperature, irradiance, conditioning/control energy, optional information-layer energy, water/edge-seal inspection, and representative thermal-glazing metrics. Use a coupon before a representative IGU; use the same illumination, thermal boundary conditions and logging interval for candidate and baseline.

## Decision rule

If the candidate cannot show a favorable or explicitly justified trade-off against the matched passive/BIPV baseline for the target climate/orientation, reframe it as a non-vision BIPV/spandrel product. Do not substitute a generic standard-test PV result for façade-level optical/thermal evidence.
