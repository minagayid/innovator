# Intended use

NeuroForge V1 is a research-only evidence and model registry for Parkinson
disease dopaminergic cell-replacement studies. It supports literature synthesis,
model comparison, mechanism-to-readout mapping, and hypothesis prioritization.

It is **not** for diagnosis, prognosis, treatment selection, treatment
monitoring, clinical decision support, individualized response prediction,
dosing, delivery, transplantation, manufacturing, or medication generation.

Patient-derived data do not change this boundary. The public package accepts
only synthetic, public, or properly governed aggregated records.
