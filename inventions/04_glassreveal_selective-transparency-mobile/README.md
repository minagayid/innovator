# GlassReveal — Selective-Transparency Mobile

GlassReveal is a **rear selective-reveal** design study, not a fully transparent phone. A normal opaque display, battery, radio/thermal spine and service cassette remain intact. The research hypothesis is limited to a user-triggered rear optical laminate over an intentionally visible cassette.
