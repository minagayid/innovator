# Horizon-Weave: Refined Research Architecture

## Reframed concept

**Horizon-Weave** is not a portal machine. It is a name for a disciplined research workflow that keeps three often-confused mathematical objects separate:

| Object | Mathematical role in this package | Explicit non-claim |
|---|---|---|
| Traversable-wormhole ansatz | A prescribed horizon-free metric used to derive throat and radial NEC diagnostics. | No material source, stability, formation, or engineering route is supplied. |
| Black-hole exterior | A normalized Schwarzschild-lapse comparison that illustrates a horizon-bearing geometry. | It is not used as a tunnel or endpoint. |
| White-hole region | A term from idealized time-reversed/maximally extended geometry discussed only in the source boundary. | It is not a maintained outlet, power source, or control mechanism. |

This separation is essential. The Morris–Thorne construction made horizon-free traversability a conditional question about a spacetime geometry and its stress-energy, not a recipe for building an aperture. Their cited discussion identified an extreme tension/energy requirement for the throat [1]. The topological-censorship theorem and quantum-inequality analysis each supply further conditional constraints, rather than a maintenance technique.[2] [3]

## Mathematical candidate and rejection gate

The toy family has \(\Phi=0\) and

\[
b(r)=r_0\left(\frac{r_0}{r}\right)^\alpha,\qquad r_0>0,\quad \alpha>0.
\]

Its derived radial NEC diagnostic is

\[
\rho+p_r=-\frac{(\alpha+1)r_0^{\alpha+1}}{8\pi r^{\alpha+3}}<0.
\]

The computed result is therefore a **diagnostic of the ansatz’s assumed stress-energy requirement**. It does not solve the more important inverse problem: whether an admissible, stable, quantum-consistent physical source can generate the geometry. Because that inverse problem is unresolved, the architecture terminates at a no-build gate.

## Research outputs

The repository package contains a fully reproducible finite calculation, regression tests, flat-space negative control, horizon-lapse comparison, parameter/refinement study, source/parameter/output hashes, and a proof-gap ledger. It is intended to help distinguish the following statements:

| Statement | Current status |
|---|---|
| “The selected metric family’s code reproduces its analytic NEC formula on the tested grids.” | **Computed/verified implementation claim.** |
| “The selected metric family is a stable solution sourced by physically realizable matter.” | **Unresolved.** |
| “A black-hole/white-hole pair maintains a wormhole.” | **Not supported; no model supplied.** |
| “Horizon-Weave is a portal invention ready to build.” | **Rejected.** |

## Smallest meaningful future research gate

The next meaningful theoretical task is not a larger parameter sweep. It is a self-consistent, explicitly specified field-theory source model with conservation, quantum-inequality analysis, well-posed evolution, perturbative stability, and causal-boundary analysis. A successful toy-model rerun would not clear that gate.
