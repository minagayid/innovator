# Archived invention UI and samples

The files in this directory preserve the previous gallery-oriented interface, bundled demo inventions, sample prior-art cards, and example routes for reference. They are deliberately not imported by the generator-first application.

The production `.dockerignore` excludes this directory, as well as the separate `inventions/`, `related-projects/`, and prior-invention asset folders. No archived invention record is deleted from the Git repository.
