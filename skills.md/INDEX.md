# Skills Index

This repository intentionally uses a directory named **`skills.md/`** to preserve the requested project path while keeping each reusable skill as a complete, installable package rather than flattening its supporting scripts and templates into one Markdown file.

| Collection | Purpose | Entry point |
|---|---|---|
| [`eureka_skill`](./eureka_skill/) | Advanced mathematics, innovation research, high-integrity computation, design-space exploration, and formal-claim auditing. | [`COLLECTION.md`](./eureka_skill/COLLECTION.md) and [`eureka-skill/SKILL.md`](./eureka_skill/skills/eureka-skill/SKILL.md) |

The collection documentation explains scope and release validation. Each directory beneath `eureka_skill/skills/` is a standalone skill package with its own `SKILL.md`.
