# Evidence ledger schema

Use one row per claim or mechanism. Preserve the exact source URL and location when available.

| Field | Requirement |
|---|---|
| Claim | State one falsifiable claim or mechanism, not a whole article summary. |
| Source | Prefer primary paper, official specification, dataset, patent/prior-art record, or authoritative institution. |
| Method/domain | Record the study design, model, sample, operating regime, or engineering context. |
| Baseline | State the comparison or null condition. |
| Result | Record the observed, derived, or reported outcome without widening its scope. |
| Limitation | Include confounders, uncertainty, missing data, scale limits, and failure modes. |
| Exact location | Use a stable URL, DOI, section, figure, table, or page when possible. |
| Status | Mark supported, contradicted, unresolved, assumption-dependent, or proposed. |

## Source discipline

Treat search snippets and secondary summaries as leads. Open the source before relying on it. Do not infer that a gap means no prior work exists. Record search vocabulary and date window so another researcher can reproduce the boundary.
