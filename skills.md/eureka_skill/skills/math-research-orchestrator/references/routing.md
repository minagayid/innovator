# Specialist Routing and Handoff

## Handoff schema

| Field | Content |
|---|---|
| Objective | One measurable question or decision |
| Evidence | Verified findings and links to artifacts |
| Assumptions | Explicit, testable, and confidence-labeled |
| Open questions | Unresolved alternatives or proof obligations |
| Requested operation | Critique, search, synthesis, ideation, derivation, or computation |
| Output | Exact file, table, code, or decision format |
| Stop condition | What ends the current pass |

## Escalation rules

Escalate to research when the answer depends on prior art or current external facts. Escalate to advanced mathematics when a claim has quantifiers, invariants, formal derivations, or numerical evidence. Escalate to innovation when the user seeks a new mechanism or design. Return to critical/creative thinking whenever a result is surprising, underdetermined, or likely to be overclaimed.

## Evidence labels

Use **verified** for directly checked artifacts or sources, **computed** for reproducible finite outputs, **inferred** for reasoned synthesis, **hypothesis** for a falsifiable proposal, and **unknown** for unresolved matters.
