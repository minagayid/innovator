# Source Hierarchy and Claim Ledger

## Preferred evidence order

1. Primary peer-reviewed papers, preprints from identifiable authors, official datasets, standards, and original technical reports.
2. Systematic reviews, meta-analyses, benchmark papers, and authoritative textbooks.
3. University, government, laboratory, or professional-society summaries.
4. Reputable journalism or practitioner material for context and discovery.
5. Search snippets, unsourced posts, and generated summaries only as leads; never use them as final evidence.

## Claim ledger fields

| Field | Required content |
|---|---|
| Claim | One sentence with a clear subject and predicate |
| Source | Stable URL, DOI, or archival identifier |
| Evidence | Method, data, theorem, or quotation supporting the claim |
| Scope | Population, parameter range, assumptions, and date |
| Limitation | Bias, uncertainty, missing case, or competing result |
| Status | Supported, contradicted, unresolved, or assumption-dependent |

## Synthesis rule

When sources disagree, preserve both claims, identify whether the disagreement is definitional, methodological, statistical, or substantive, and propose the cheapest discriminating test.
