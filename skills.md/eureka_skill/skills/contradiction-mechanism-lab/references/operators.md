# Contradiction operators

Use these as prompts, not as guaranteed solution rules.

| Operator | Question |
|---|---|
| Temporal separation | Can the system optimize different requirements at different times or phases? |
| Spatial separation | Can the conflict be localized to different regions, layers, paths, or users? |
| Scale separation | Can a property be changed at micro, meso, and macro scales without violating the target function? |
| Selective permeability | Can the system pass one flow, frequency, species, or signal while blocking another? |
| Adaptive switching | Can a sensed state select among modes while preserving stability and fail-safe behavior? |
| Modularity | Can a replaceable or reconfigurable subsystem isolate cost, wear, or uncertainty? |
| Inversion | What happens if the assumed objective, flow direction, or sequence is reversed? |
| Feedback | Can measurement and actuation reduce the conflict, and what delay or instability does that introduce? |
| Resource substitution | Can energy, material, information, time, or labor substitute for one another? |
| Lifecycle coupling | Can production, use, maintenance, recovery, and reuse be designed as one system rather than separate stages? |

For each operator, state the conserved quantity, the new control variable, the added failure mode, and the experiment that could distinguish the mechanism from a baseline.
