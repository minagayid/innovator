# Breakthrough Pattern Prompts

Use these patterns to generate candidates, then validate them rather than treating history as a recipe.

| Pattern | Prompt |
|---|---|
| Anomaly | What observation does the current model explain poorly? |
| Reframing | What changes if the object, unit, or objective is represented differently? |
| Mechanism transfer | Which neighboring field solves a structurally similar bottleneck? |
| Composition | Can two mature mechanisms be combined without violating their assumptions? |
| Inversion | What if the usual cause/effect, producer/consumer, or search/verification direction is reversed? |
| Enabling tool | Which new measurement, computation, material, or interface makes an old idea testable? |
| Limiting case | What must the idea reduce to in a known regime? |
| Productive contradiction | Which requirements appear incompatible, and can the conflict be moved to another layer? |

For each candidate, record the original analogy, the preserved structure, the broken analogy, and the test that could disconfirm the transfer.
